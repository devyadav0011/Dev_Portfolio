# 🎬 Dev Kumar — Netflix-Inspired Portfolio

A cinematic, Netflix-inspired developer portfolio built to showcase projects, technical skills, open-source work, and startup initiatives through an immersive streaming-platform experience.

> **Building Products. Creating Impact. Exploring What's Next.**

## ✨ Overview

This portfolio reimagines the traditional developer portfolio as an interactive streaming experience, combining cinematic visuals, horizontal project carousels, smooth animations, and a premium dark interface.

Built around the journey of **Dev Kumar** — a software developer, B.Tech Computer Science & Engineering student, and founder of NIMBLUX.

## 🚀 Features

- 🎬 Cinematic hero section with bold typography and atmospheric backgrounds.
- 👤 Interactive profile selection for recruiters, developers, and startup founders.
- 🎞️ Netflix-inspired horizontal project carousels.
- 🖱️ Interactive project cards with descriptions, technologies, and links.
- 🔎 Search and filtering for exploring projects.
- 🤖 AI and SaaS project showcase.
- 💻 Open-source repository integration.
- 🏆 Achievements, hackathons, and community showcase.
- 📱 Responsive layouts for desktop, tablet, and mobile.
- ♿ Accessibility-focused interactions and reduced-motion support.

*Feature availability depends on the current implementation.*

## 🎨 Design Philosophy

The portfolio draws inspiration from streaming-platform browsing experiences while maintaining an independent developer-focused identity.

- Dark cinematic visuals.
- Clean typography and strong hierarchy.
- Project-first storytelling.
- Smooth, purposeful animations.
- Responsive and accessible interactions.
- Real project information rather than invented achievements.

This is an independent portfolio project and is not affiliated with or endorsed by Netflix.
